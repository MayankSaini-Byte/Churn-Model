# ChurnSight — Telco Customer Churn Prediction

An ML-powered web app that predicts whether a telecom customer is likely to churn, built with **Logistic Regression**, **Flask**, and a modern dark-themed dashboard.

## Live Demo
Run locally at `http://127.0.0.1:5000` after following the setup steps below.

## Features
- Predicts churn probability with an optimal decision threshold (not just 0.5)
- Risk levels: Low / Medium / High with actionable recommendations
- Animated probability gauge and circular progress rings
- Responsive dark glassmorphism UI

## Tech Stack
| Layer | Technology |
|---|---|
| ML Model | Scikit-learn Logistic Regression |
| Backend | Python · Flask |
| Frontend | HTML · Vanilla CSS · JavaScript |
| Dataset | IBM Telco Customer Churn |

## Setup

### 1. Clone the repo
```bash
git clone https://github.com/MayankSaini-Byte/Churn-Model.git
cd Churn-Model
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Train the model
Open and run `notebooks/model.ipynb` top-to-bottom. This generates the `.pkl` and `.json` files in `models/`.

### 4. Run the app
```bash
python app.py
```
Then open [http://127.0.0.1:5000](http://127.0.0.1:5000).
